# PASTA Threat Model Analysis for E-Commerce Application

## Overview
Conducted a comprehensive threat modeling assessment for a sneaker e-commerce application using the PASTA (Process for Attack Simulation and Threat Analysis) methodology. Identified critical vulnerabilities, analyzed attack paths, and developed a phased security control implementation strategy.

**Skills Demonstrated:**
- PASTA threat modeling methodology (7-stage framework)
- Attack surface analysis and decomposition
- Threat identification and prioritization
- Vulnerability analysis and exploitation path mapping
- Attack tree modeling
- Risk scoring and impact assessment
- Security control recommendation and implementation planning
- PCI-DSS compliance considerations

**Tools & Frameworks:**
- PASTA (Process for Attack Simulation and Threat Analysis)
- MITRE ATT&CK framework
- CVE database references
- Attack tree modeling
- Data flow diagram analysis
