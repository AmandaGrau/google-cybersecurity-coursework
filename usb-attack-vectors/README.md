# USB Baiting Attack Investigation

## Overview
Investigated a USB drive found in a hospital parking lot with the organization's logo printed on it. Using virtualization software to safely analyze the device without risking network infection, assessed the attack vectors, identified potential threats, and evaluated security controls to mitigate USB baiting attacks.

**Skills Demonstrated:**
- USB baiting attack recognition and analysis
- Virtualization software for safe device investigation
- Attack vector identification and assessment
- Risk analysis and threat modeling
- Security control implementation (technical, operational, managerial)
- Social engineering threat assessment

**Tools Used:**
- Virtualization software (isolated environment for USB analysis)
- Security control frameworks (technical, operational, managerial)
