# DDoS Attack Incident Analysis Using NIST CSF

## Overview
Analyzed a distributed denial-of-service (DDoS) attack that disrupted network services for two hours due to an unconfigured firewall. Applied the NIST Cybersecurity Framework's five core functions (Identify, Protect, Detect, Respond, Recover) to develop comprehensive security improvements and incident response procedures.

**Skills Demonstrated:**
- NIST Cybersecurity Framework (CSF) application
- Incident response and analysis
- DDoS attack mitigation strategies
- Firewall configuration and rule management
- Network security vulnerability assessment
- IDS/IPS implementation
- Post-incident review and documentation
- Security awareness training development

**Tools & Frameworks Used:**
- NIST Cybersecurity Framework (CSF)
- Firewall rule management and ICMP filtering
- Network monitoring software
- Intrusion Detection/Prevention System (IDS/IPS)
- Firewall logging and analysis
