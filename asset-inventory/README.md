# Home Asset Inventory and Classification

## Overview
Created a comprehensive asset inventory for a home network, cataloging eight devices and classifying them by sensitivity level to establish appropriate security controls and access designations.

**Skills Demonstrated:**
- Asset inventory management
- Data classification and sensitivity assessment
- Network asset identification
- Risk-based access control designation
- Security categorization (Confidential, Restricted, Internal-Only, Public)
- Documentation and record-keeping

**Tools & Frameworks:**
- Asset inventory spreadsheet methodology
- Data classification framework
- Access designation model

## Files
- **[Home Asset Inventory](home_asset_inventory.pdf)** - Complete asset inventory with device details, network access patterns, ownership, location, and sensitivity classifications
