# Phishing Incident Response Using Playbook

## Overview
Structured incident response investigation following a phishing alert at a financial services company. As a level-one SOC analyst, investigated a suspicious file download using the organization's phishing response playbook, documented findings, and escalated the confirmed incident to level-two personnel for containment.

**Skills Demonstrated:**
- Playbook adherence and structured incident response
- Alert triage and severity evaluation
- Phishing analysis and indicator identification
- Email forensics and metadata analysis
- File hash correlation with threat intelligence
- Incident documentation and ticketing
- Escalation judgment and communication
- Technical handoff to senior analysts

**Tools & Resources Used:**
- Phishing response playbook with investigation flowchart
- Alert ticketing system for documentation
- Threat intelligence databases for file hash verification
- Incident handler's journal for investigation tracking
