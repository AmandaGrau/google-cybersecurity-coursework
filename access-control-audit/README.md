# Access Control Incident Analysis

## Overview
Investigated unauthorized payroll modification incident by analyzing event logs and employee directory to identify access control failures that allowed a former contractor to retain administrative privileges for nearly four years after termination.

**Skills Demonstrated:**
- Event log analysis and correlation
- Access control audit and investigation
- Insider threat identification
- Authentication and authorization review
- Role-based access control (RBAC) principles
- Principle of least privilege application
- Security policy recommendations

**Tools Used:**
- Event logging systems
- Employee directory analysis
- Access control frameworks

## Files
- **[Access Control Incident Analysis](access_control_worksheet.pdf)** - Investigation worksheet with findings and recommendations
- **[Activity Log](activity_log.pdf)** - Activity log depicting unauthorized user account details
- **[Employee Directory](access_control_worksheet.pdf)** - Reference table of employees with Admin privileges
