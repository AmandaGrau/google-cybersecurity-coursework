# Brute Force Attack Analysis: Incident Investigation and Response

## Overview
Investigation of a website compromise through brute force attack using tcpdump log analysis. Identified network protocols involved, documented the attack sequence, and recommended security controls to prevent future incidents.

**Skills Demonstrated:** 
- tcpdump log analysis
- Network protocol identification (DNS, HTTP)
- Incident documentation
- Brute force attack mitigation
- OS hardening techniques

**Tools Used:** 
- tcpdump
- TCP/IP model analysis
- Sandbox environment testing

- **[Brute Force Attack Analysis](brute_force_attack_analysis.pdf)** - Complete incident analysis with protocol identification and remediation recommendations
