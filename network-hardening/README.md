# Network Hardening: Security Risk Assessment

## Overview
Security risk assessment identifying critical vulnerabilities following a data breach at a social media organization. Selected and justified three network hardening measures to address authentication weaknesses, password security gaps, and firewall configuration deficiencies.

**Skills Demonstrated:** 
- Vulnerability assessment
- Network hardening strategies
- Security risk analysis
- Multi-layered defense planning
- Security recommendations

**Tools & Methods:** 
- Multi-factor authentication (MFA)
- Password policy enforcement
- Firewall maintenance 
- Network security best practices

- **[Security Risk Assessment Report](security_risk_assessment_report.pdf)** - Analysis of vulnerabilities and detailed hardening recommendations
- **[Network Hardening Tools Reference](network_hardening_tools.pdf)** - Framework documentation for hardening methods
