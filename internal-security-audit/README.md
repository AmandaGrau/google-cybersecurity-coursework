# Internal Security Audit: Controls and Compliance Assessment

## Overview
Comprehensive security audit of Botium Toys' IT infrastructure, evaluating existing controls and compliance with industry regulations to identify gaps and provide prioritized remediation recommendations.

**Skills Demonstrated:** 
- Security controls assessment 
- Compliance evaluation (PCI DSS, GDPR, SOC)
- Risk analysis 
- Audit documentation
- Security recommendations

**Frameworks Used:** 
- NIST Cybersecurity Framework (CSF)
- PCI DSS
- GDPR
- SOC 2

## Files
- **[Controls and Compliance Checklist](audit_controls_and_compliance_checklist.pdf)** - Assessment results identifying implemented and missing controls
- **[Audit Scope and Risk Assessment](scope_goals_risk_assessment.pdf)** - Original audit parameters and risk evaluation
- **[Control Categories Reference](control_categories.pdf)** - Framework documentation for control types and purposes
