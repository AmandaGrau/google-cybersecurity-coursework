# Network Traffic Analysis: SYN Flood Attack Detection and Response

## Overview
Investigated web server outage affecting company website accessibility. Analyzed Wireshark packet captures to identify a SYN flood denial-of-service attack overwhelming the server with half-open TCP connections, implemented immediate mitigation, and documented findings for management escalation.

**Skills Demonstrated:** 
- Wireshark packet capture analysis
- TCP three-way handshake analysis
- DoS attack pattern recognition
- Network traffic anomaly detection
- Incident response and containment
- Firewall configuration

**Tools Used:** 
- Wireshark
- Network monitoring systems
- Firewall configuration
- TCP/IP protocol analysis
