# Risk Assessment and Scoring for Commercial Bank

## Overview
Conducted a comprehensive risk assessment for a commercial bank, evaluating five key threats to organizational security and funds. Used quantitative risk scoring methodology to prioritize vulnerabilities and develop a risk register for resource allocation.

**Skills Demonstrated:**
- Quantitative risk assessment and analysis
- Risk scoring using likelihood × severity methodology
- Risk register development and maintenance
- NIST Cybersecurity Framework (CSF) application
- Vulnerability prioritization and resource allocation
- Operational environment analysis
- Regulatory compliance consideration

**Tools & Frameworks:**
- Risk register methodology
- Risk scoring matrix (1-3 scale for likelihood and severity)
- NIST Cybersecurity Framework
- Quantitative risk analysis
