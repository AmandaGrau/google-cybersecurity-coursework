# Access Control Incident Analysis - Least Privilege

## Overview
Analyzed an access control incident where internal documents were accidentally exposed publicly on social media, identifying control failures and developing recommendations based on NIST SP 800-53: AC-6 (Least Privilege) framework.

**Skills Demonstrated:**
- Security incident analysis and root cause identification
- NIST SP 800-53 framework application (AC-6: Least Privilege)
- Access control evaluation
- Risk mitigation strategy development
- Incident documentation and reporting

**Tools & Frameworks:**
- NIST SP 800-53: AC-6 (Least Privilege)
- Role-Based Access Control (RBAC) principles
- Security audit methodology
