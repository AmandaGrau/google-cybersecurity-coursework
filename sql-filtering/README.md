# Apply Filters to SQL Queries

## Overview
Used SQL filter operators (AND, OR, NOT, LIKE) to investigate security incidents involving suspicious login activity and identify employee machines requiring security updates across multiple departments.

**Skills Demonstrated:**
- SQL query construction and filtering techniques
- Combining multiple conditions with AND operator
- Using OR operator for alternative criteria
- Applying NOT operator for exclusions
- Pattern matching with LIKE operator and wildcards
- Database querying for security investigations
- Analyzing login attempts and employee data
- Targeting specific datasets for security maintenance

**Tools Used:**
- SQL (Structured Query Language)
- MariaDB database system
- Linux command line interface
