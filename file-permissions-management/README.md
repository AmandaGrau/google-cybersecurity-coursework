# Linux File Permissions Management

## Overview
Managed file and directory permissions using Linux commands to implement security policies and principle of least privilege. Examined current permissions, identified authorization issues, and used chmod to configure appropriate access controls.

**Skills Demonstrated:**
- Linux command line
- chmod usage
- File permission interpretation
- Security policy implementation
- Principle of least privilege
- Hidden file management

**Tools Used:** 
- Linux Bash shell
- ls command
- chmod command
