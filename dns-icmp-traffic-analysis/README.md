# DNS and ICMP Traffic Analysis: Network Layer Communication

## Overview
Analysis of DNS and ICMP traffic to troubleshoot website connectivity issues. Identified DNS service failure through tcpdump log examination and determined root cause of "port unreachable" errors affecting customer access.

**Skills Demonstrated:** 
- tcpdump log analysis
- DNS protocol troubleshooting 
- ICMP error interpretation 
- Network layer communication analysis
- Incident investigation

**Tools Used:** 
- tcpdump
- TCP/IP model analysis
- DNS/UDP protocol analysis
