### Brute Force Attack Investigation
Analyzed web server compromise where attacker used default credentials to gain access, then injected malicious JavaScript that distributed malware to site visitors. Documented attack timeline, identified vulnerabilities, and provided security recommendations.

**Key Skills:** Incident response, web server log analysis, attack pattern recognition, malware investigation, security recommendations

### SYN Flood DDoS Attack Analysis
Used Wireshark to analyze denial-of-service attack that overwhelmed web server with half-open TCP connections. Identified attack pattern, documented findings using NIST Cybersecurity Framework, and implemented immediate firewall blocks.

**Key Skills:** Wireshark packet analysis, TCP/IP protocols, DoS attack detection, NIST CSF application, incident response

[View Project →](syn-flood-attack-analysis/)

---

### Python Security Automation
Wrote Python script to automate updating IP address allow lists - reads file, removes IPs from a remove list, writes updated results back. Demonstrates file operations, string methods, and list manipulation for security tasks.

**Key Skills:** Python programming, file operations, security automation, access control management

[View Project →](security-automation/)

---

### DNS & ICMP Traffic Analysis
Troubleshot website connectivity issues using tcpdump to capture network traffic. Identified that DNS service on port 53 wasn't responding, causing "port unreachable" errors. Documented findings and recommended troubleshooting steps.

**Key Skills:** tcpdump analysis, DNS protocol troubleshooting, ICMP error interpretation, network layer communication, incident investigation

[View Project →](dns-icmp-traffic-analysis/)
